# RobotSubeEscaleras - Modelo 3
----
En esta práctica hemos creado un robot que cumple con los siguientes requisitos:
- Esquiva obstáculos
- Es capaz de subir 1 peldaño
- Dimensiones: 25x25x25
- Inicio de movimiento mediante una interfaz inalámbrica

# PESOS APROXIMADOS: 

## Base del robot: 

1. 3 Servo Parallax Feedback 360 - 96 g
2. 1 placa Arduino Uno - 25 g
3. 1 Batería LiPo 2S, 2000 mAh - 110 g
4. Peso de la carcasa de PLA (10 x 15 x 0.05): 400 g

Peso total aprox: 631

## Brazos del robot: 

Estructuras de PLA (0.25 x 0.02 x 0.03) - 65 g por brazo

## Soporte del robot (segunda base)

1. ESP32 DevKit - 10 g
2. Sensor ultrasónico HC-SR04 - 8 g
3. 2 Servo Parallax Feedback 360 - 64 g
4. Peso de la carcasa de PLA rellena (0.1 X 0.15 X 0.01) - 180 g

Peso total aprox: 262
