# Robot Sube Escaleras

Proyecto de **Mecatrónica** del Grado en Ingeniería de Robótica Software de la Universidad Rey Juan Carlos (URJC).

## Descripción del proyecto

El objetivo de este proyecto es diseñar, fabricar y programar un robot terrestre capaz de subir escaleras de forma estable y funcional. Para ello, se desarrollará una solución robótica que integre diseño mecánico, electrónica, sensores, actuadores y software de control.

El proyecto abarca el proceso completo de desarrollo, desde la planificación y el diseño conceptual hasta la construcción del prototipo, su programación y la validación mediante pruebas.

## Objetivos

- Diseñar y construir una estructura robótica propia adaptada al reto de subir escaleras.
- Desarrollar un sistema de locomoción sin ruedas.
- Implementar el control necesario para lograr un desplazamiento estable.
- Incorporar sensores que permitan detectar el entorno y reaccionar ante obstáculos.
- Desarrollar el comportamiento autónomo necesario para aproximarse a una escalera.
- Integrar los sistemas mecánicos, electrónicos y software en un único prototipo.
- Realizar pruebas para comprobar el funcionamiento del robot y evaluar sus resultados.

## Requisitos generales

El diseño deberá respetar las restricciones establecidas en el enunciado, incluyendo las dimensiones máximas, la alimentación mediante baterías recargables, la fabricación propia de la estructura y la disponibilidad de una interfaz básica para iniciar y detener el funcionamiento.

El robot deberá demostrar su capacidad para aproximarse a la escalera evitando obstáculos y subir al menos un peldaño dentro de los límites de tiempo establecidos en el enunciado.
